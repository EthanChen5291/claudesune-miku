Library audition

Every entry in src/lib/*.js is an unratified hand-written seed (DECISIONS D21). Each link below plays every current entry of one kind, back to back, one per section — press play and listen straight through. Mark keep/kill in CHECKLIST.md as you go.

  • unison packs — CLICK TO PLAY
    72 progressions + 12 drum-loop rhythms + 91 observed voicings, extracted from audios/ (D29). Separate pool from the ldrolez set. Piano playback; NEEDS EAR flags the entries whose filename label disagrees with the notes; ONSETS ONLY marks drum parts whose source has no dynamics. Regenerate: node scripts/audition-unison.mjs
  • facets — WHAT WORKS, PIECE BY PIECE
    D53. Three tabs. pairs: 467 two-chord loops — every root motion the corpus plays, each destination offered under the two qualities it actually takes; a ✓ records the MOVE and the CHORD as separate facts, so "Cm→Bm yes, Cm→B no" survives instead of cancelling out. Sorted by leverage (thin corpus rows first) so clicks land where they change the model. textures: one harmony, 7 formats, multi-select — four are library figurations (arpeggio, oom-pah, ostinato), not block chords. cadences: each loop ending three ways, as written / wrap suspended / penultimate suspended. Skipping a tile is NOT a rejection — only ✗ is. Export, then node scripts/import-verdicts.mjs <file.json>. Regenerate: node scripts/audition-facets.mjs
  • judge — 36 CONTROLLED TRIALS
    D52/D54. 36 trials — A/B, layer and open — keyboard-driven, ~10 minutes. Every side lists six tones (block, wide pad, arpeggio, wide arp, oom-pah, roots-only) as rows: click the name to mark it as one that works on that chord, the triangle to play it, the thumbs-down to reject it. Liked on both sides of a trial → BOTH badge. Votes are keyed by the harmony and feed the same facet bags as facets.html. 1–6 play a tone on A, shift+ for B. Small notes box on every trial, saved as you type and kept even if you skip. Answers record which pattern was sounding, so the tally can be split by texture. Regenerate: node scripts/audition-judge.mjs
