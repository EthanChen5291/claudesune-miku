# F-minor house track — build notes

## Tools and format

- Everything is generated by one self-contained Python script (`house_track.py`,
  numpy only) that lives in each version folder. A single event list
  (stem -> `(time, duration, pitch, gain)`) drives two renders:
  - **`fminor_house.wav`** — stereo 44.1 kHz / 16-bit, the listenable deliverable
    (127.9 s = 64 bars at 122 BPM plus a 2 s ring-out).
  - **`fminor_house.mid`** — the same notes as a format-1 General MIDI file
    (drums on ch 10, bass/stab/lead/arp/pad on melodic channels) for DAW import.
- Synthesis is band-limited additive (saw-ish leads/stabs/pads, sub+saw bass)
  plus seeded-noise drums, with a beat-keyed sidechain "pump" on bass/chords/arp,
  Haas-widened pads, and a dotted-8th stereo delay on lead and arp.
  Per-event noise seeds are deterministic, so unchanged parts render
  bit-identically across versions — each change request's scope was verified
  numerically (per-stem RMS and sample diffs printed by the script).
- Re-render any version with `python3 house_track.py` inside its folder.

## v0 — initial track

- F minor, 122 BPM, form A B A' B with 16-bar sections over an
  Fm–Db–Ab–Eb (i–VI–III–VII) one-chord-per-bar loop; four-on-the-floor kick,
  claps on 2+4, offbeat rolling bass with an octave pickup.
- A (verse): offbeat closed hats, sparse open hat, two chord stabs per bar,
  4-bar lead motif in C4–C5. B (chorus) lifts: melody moves up to C5–C6 and
  doubles in rhythmic density, plus sustained pads, an 8th-note arp,
  open hats on every offbeat, 16th hat ticks, and a shaker.
- A' returns the exact A melody/harmony with busier drums: ride cymbal 8ths,
  extra 16th closed hats, and a ghost clap at each 4-bar turnaround.

## v1 — busier hi-hats (hats only)

- Verses (A and A'): closed hats now fill a full 16th-note grid (accents kept
  on the offbeats), and the open hat plays every bar instead of every other bar.
- Chorus: 16th-note closed-hat ticks brought up in level, plus a new open-hat +
  closed-hat pickup into every downbeat (beats 3.75 / 3.875).
- Scope check: only the `chat`/`ohat` stems changed; kick, clap, shaker, ride,
  bass, chords, and melody stems are numerically identical to v0.

## v2 — bigger chorus lift (B sections only)

- Chorus lead moved up an octave (now C6–C7) with the previous C5–C6 line kept
  underneath as a second voice — higher register and a thicker, two-voice lead.
- Chorus arp densified from 8th notes to rolling 16ths with octave-up accents
  on every offbeat; pads gained an added octave top voice.
- Scope check: the first A section is bit-identical to v1 and A' events are
  unchanged (the only sample difference is ~0.8 s of the chorus delay tail
  ringing across the B->A' boundary). Chorus RMS rose 0.341 -> 0.358 while
  verse RMS is unchanged.

## v3 — darker bass sound (timbre only)

- Bass patch swapped from two bright detuned saws (+light sub, harmonics up to
  ~2.4 kHz) to a dark, round patch: steep harmonic rolloff capped near 650 Hz,
  heavier sub sine, and gentle tanh saturation for warmth. Envelope unchanged.
- The MIDI mirror's bass program changed GM 39 "Synth Bass 1" -> 40
  "Synth Bass 2" to reflect the patch swap; note data untouched.
- Scope check: bass event list is identical to v2 (verified), and only the bass
  stem's audio changed. Spectral centroid of the bass fell 121.6 Hz -> 105.0 Hz
  and energy above 500 Hz dropped from 1.7% to 0.4% — measurably darker.
