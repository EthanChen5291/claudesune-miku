# "Undertow" — build notes

## Tools & format

- **Everything is generated by one self-contained Python script per version**
  (`vN/groove.py`, Python 3 + numpy only, no other dependencies). The piece is
  composed as note-event data (time in eighth-note units, duration, pitch,
  velocity) for four parts: drums, bass, electric-piano keys, and saw lead.
- Each script writes two deliverables into its own folder:
  - `groove.mid` — standard MIDI file (format 1, 480 PPQ, tempo + 7/8 time
    signature meta, GM programs), openable/renderable in any DAW.
  - `groove.wav` — 44.1 kHz 16-bit stereo render (~48 s) from a built-in numpy
    softsynth (FFT-filtered saws, sine-sweep kick, noise hats/snare, EP-style
    keys), so the piece is listenable with no extra software.
- Musical spec: 7/8 at 140 BPM (quarter = 140), grouped 2+2+3, D dorian,
  form A B C A′ with 8-bar sections. The C bridge withholds the bass entirely
  (drums thin to kick/sidestick/ride, keys become high floating pads); the
  bass riff re-entering under a crash at bar 25 is the payoff.
- Each `vN/` is self-contained: script + MIDI + WAV. Regenerate any version
  with `python3 vN/groove.py`.

## v0 — initial version

- Composed the full 32-bar arrangement: two-bar D-dorian bass riff (with the
  B-natural color tone) in the A sections, F–G–Am motion in B, bassless
  pad bridge in C, and the identical riff returning in the final A.
- Drum groove built on the 2+2+3 grid (kick 1 & 5, snare 3 & 6, straight
  eighth hi-hats with grouping accents), section-turn fills, crash on the
  payoff downbeat; lead melody is a call-and-response motif, lifted a third
  midway, with a long-arc B melody and sparse high floating notes in C.
- Verified programmatically: zero bass events in bars 17–24, section RMS
  drops from ~0.20 to ~0.085 in the bridge and returns to ~0.20 at the
  payoff; MIDI chunk structure validates.

## v1 — change request 1: swing/shuffle on the hi-hats only

- Added `HAT_SWING = 0.60`: the offbeat eighth of each beat-group pair in the
  2+2+3 grid (grid positions 2, 4, 6 of the bar, i.e. indices 1/3/5) now lands
  at a 60% shuffle ratio (+0.2 eighth-note, ≈43 ms late) instead of dead
  center; the lone 7th eighth stays straight.
- Applied strictly to hi-hat notes (closed/open hat). The bridge's ride
  cymbal, kick, snare, sidestick, toms, crashes, and all velocities/durations
  are untouched.
- Verified by note-level diff against v0: exactly 71 closed-hat notes moved
  (all by +0.2 eighth); bass, keys, lead, and every other drum voice are
  event-identical.

## v2 — change request 2: sparser lead melody in the A sections only

- Rewrote `lead_a_section` (shared by both A sections): 40 → 16 notes per
  section. Ornamental 16th-note runs and passing tones were dropped in favor
  of longer holds and full beats of air (bar 4 is a lone pickup note, bar 6
  is empty).
- The motif's skeleton is preserved so the payoff still reads as "the same
  tune": D5 anchor, the C5→A4 fall, the dorian-sixth answer, the lifted-third
  statement, and the long D5 cadence.
- Verified by note-level diff against v1: lead events in B and C are
  byte-identical, and drums (including the v1 hat swing), bass, and keys are
  event-identical; only the two A-section lead lines changed.
