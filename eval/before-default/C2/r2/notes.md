# Seven Over — build notes

## Tools and format

- Everything is generated by a single dependency-light Python script, `build_song.py`
  (numpy + stdlib only), checked into each version directory. It composes the piece
  as a flat list of note events, then writes two deliverables side by side:
  - **`seven_over.mid`** — standard MIDI file (format 1, 5 tracks, GM programs,
    7/8 time signature, 140 BPM) for rendering/editing in any DAW.
  - **`seven_over.wav`** — 44.1 kHz / 16-bit stereo render from a small built-in
    softsynth (additive bass/EP/lead, synthesized kick/snare/hats/crash, lead echo,
    FFT-convolution room reverb), so the track is directly listenable.
- The piece: 7/8 grouped 2+2+3 at 140 BPM, D dorian throughout, form A B C A with
  8-bar sections plus a one-bar coda hit. Instruments: drums, electric bass,
  EP keys, square-wave lead. Section C is the bridge — the bass is withheld
  entirely (verified: bass-bus RMS = 0.000 across C), drums thin to hats/sidestick,
  and a bar-8 snare build sets up the bass + crash re-entry that opens the final A.
- Each `vN/` is self-contained: script + MIDI + WAV. Rerun with
  `python3 build_song.py` to regenerate both outputs deterministically.

## v0 — initial version

- Composed the full arrangement: Dm7-centered dorian vamp in A (Dm7/G7/Cmaj7),
  a lifted B progression (Fmaj7–G7–Am7…), and a floating bridge C
  (Fmaj7/Em7/G7sus pads, sparse high lead, no bass).
- Built the groove around the 2+2+3 grouping: kick on group starts, snare
  backbeats on eighths 3 and 7, accented straight-eighth hi-hats.
- Wrote the MIDI encoder and softsynth renderer; validated the .mid with a
  separate SMF parser and confirmed the section dynamics arc
  (RMS: A 0.28 → B 0.28 → C 0.09 → A 0.28).

## v1 — swing/shuffle on hi-hats only

- Off-eighth hi-hat hits (odd eighth positions in each bar) are delayed by
  0.30 of an eighth (~65% shuffle) via a `_hat_pos()` helper used only in hat
  event generation; on-beat hats stay put.
- Applies to closed and open hats in every section, in both MIDI and WAV.
- Verified nothing else changed: all 782 non-hat events are byte-identical to
  v0; 96 off-beat hats moved by exactly +0.30 eighth, 128 on-beat hats unchanged
  (drum noise seeds are per-event, so other drums render bit-identically).

## v2 — sparser lead in the A sections only

- Rewrote the `LEAD_A` table from 42 notes down to 17 per A section: dropped the
  16th-note runs and passing tones, lengthened the held notes, kept the theme's
  landmarks (D→A ascent, B-natural color over G7, C6 peak over Cmaj7, resolution
  to D). Both A sections read from this table, so both get the sparser theme.
- B and C leads untouched (verified event-identical to v1), as are the coda and
  all accompaniment: all 870 non-lead events are byte-identical to v1.
- The hi-hat swing from v1 is carried forward unchanged.
